# Codex 桌面端能力预检

仅当主机明确标识自身为 Codex 桌面应用后，才阅读此参考。共享辅助调用、运行时检查、修复限制和非交互式回退仍保留在 `config-preflight.md` 中。

仅在扫描具有权威目标和扫描上下文后运行预检。

在基于应用的标准或差异扫描获得权威 `scanId` 后，通过 `update_codex_security_scan_progress` 发布每个结构化的预检结果，且不改变阶段。将 `preflightChecks` 设置为所有当前结果，仅保留 `capability`、`reason`、`severity` 和 `status`；不要发送单独的阶段总数。服务器会自行推导已完成和总检查数。保持预检状态，直到辅助函数返回 `ready`，然后在单独的进度更新中推进。深度发现拥有自己的预检和进度。

当交互式桌面扫描需要修复时，展示辅助函数提供的精确配置更改，并提供 **应用并重试（推荐）**、**保持暂停** 和 **取消扫描** 选项。优先使用原生 `request_user_input`；如果不可用或出错，则使用具有相同选项的 `request_codex_security_user_input`，仅当该工具不可用或出错时才回退到聊天。切勿设置自动解析或从被拒绝或取消的输入请求中推断选择。等待而不创建目标，然后仅应用明确批准的更改，保持持久扫描运行，或仅在用户明确选择取消时才取消。

切勿在无头或非交互式会话中使用桌面输入工具。
